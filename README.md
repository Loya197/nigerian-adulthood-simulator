# nigerian-adulthood-simulator
Nigerian Adulthood Simulator 🇳🇬
About the Project
What if we could use Python to investigate the ridiculous mathematics of being an adult in Nigeria?

The Nigerian Adulthood Simulator is a beginner Python project that turns relatable Nigerian experiences into interactive, humorous simulations.

From unexpected expenses to the familiar responses of "It is well," "Jesus!" and "God abeg," this project explores the everyday logic of adulthood through code.

Project Goals
Practise Python programming through relatable, real-world scenarios.

Use user input, conditional statements, variables and scoring logic.

Turn everyday Nigerian experiences into interactive simulations.

Learn by building projects that are both entertaining and technically useful.

What I'm Learning
This project is part of my journey learning Python from the beginning. Each feature is an opportunity to understand programming concepts by applying them to situations people recognise.
